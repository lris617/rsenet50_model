# PyTorch_nn 项目说明与运行指南

## 1. 项目概览

`PyTorch_nn` 是一个基于 PyTorch 的图像回归实验项目，核心任务是根据图片预测连续值 `delta_vth`。

项目中主要有两条模型路线：

- `ResNet50` 单图回归：输入一张图片，输出一个 `delta_vth` 预测值。
- `CNN + LSTM` 时序图回归：输入同一样本的 4 张时序图片，先用 CNN/ResNet 提取每帧特征，再用 LSTM 建模序列关系，输出一个 `delta_vth` 预测值。

注意：`labels.csv` 中虽然有 `label`、`delta`、`vth` 等字段，但当前主训练脚本使用的是 `delta_vth` 作为回归目标，损失函数为 `MSELoss`。

## 2. 快速运行

```bash
cd /home/swh/rsenet50_model
```

单图 ResNet50 训练与测试：



## 5. 数据格式

### 5.1 单图数据集

`dataset` 和 `dataset14` 都是单张图片回归数据集，每个 split 下包含图片和 `labels.csv`：

```text
dataset14/
├── train/
│   ├── labels.csv
│   └── sample_*.png
├── val/
│   ├── labels.csv
│   └── sample_*.png
└── test/
    ├── labels.csv
    └── sample_*.png
```

`labels.csv` 至少需要包含：

```text
filename
delta_vth
```

训练时根据 `filename` 读取图片，根据 `delta_vth` 读取回归标签。

### 5.2 时序图数据集

`dataset4lstm14` 用于 CNN-LSTM。每个样本是一个目录，目录名来自 `labels.csv` 中的 `filename` 字段。

示例：

```text
dataset4lstm14/train/
├── labels.csv
├── 14_001/
│   ├── combined_1.png
│   ├── combined_2.png
│   ├── combined_3.png
│   └── combined_4.png
└── 14_002/
    ├── combined_1.png
    ├── combined_2.png
    ├── combined_3.png
    └── combined_4.png
```

当前 CNN-LSTM 脚本实际读取的是每个样本目录下的：

```text
combined_1.png
combined_2.png
combined_3.png
combined_4.png
```

## 6. 单图 ResNet50 路线

### 6.1 训练脚本

入口：

```bash
python PyTorch_nn/train.py
```

默认读取：

```text
PyTorch_nn/dataset/train/labels.csv
PyTorch_nn/dataset/val/labels.csv
```

主要流程：

1. 读取 `labels.csv`。
2. 按 `filename` 加载图片。
3. 将图片 resize 到 `224x224`。
4. 使用 ImageNet 均值和方差归一化。
5. 构建 `resnet50(pretrained=True)`。
6. 输出 1 维回归值。
7. 用 `MSELoss` 对齐 `delta_vth`。
8. 保存验证 loss 最好的 top3 模型。

默认关键参数：

```text
batch_size = 32
num_epochs = 1500
lr = 1e-3
optimizer = Adam
loss = MSELoss
```

训练输出：

```text
PyTorch_nn/report/day7/resnet50_peak2peak_best_epoch*_val*.pth
PyTorch_nn/report/train_val_loss7.csv
```

### 6.2 测试脚本

入口：

```bash
python PyTorch_nn/test_regression.py
```

默认测试数据：

```text
PyTorch_nn/dataset14/test/labels.csv
PyTorch_nn/dataset14/test/*.png
```

默认加载权重：

```text
PyTorch_nn/report/resnet50_peak2peak_best_epoch1472_val0.0023.pth
```

测试输出：

```text
PyTorch_nn/dataset14/test/pred_results14.csv
PyTorch_nn/dataset14/test/bias_plot14.png
```

脚本会打印每个样本的预测值、真实值、误差、MAE、MSE 和平均单样本推理时间。

## 7. CNN-LSTM 路线

### 7.1 模型结构

模型定义在：

```text
PyTorch_nn/model/cnnlstm.py
```

输入张量形状：

```text
(batch, seq, C, H, W)
```

默认 `seq = 4`，即每个样本 4 张图片。

模型流程：

1. 将 4 帧图片展开成 `(batch * seq, C, H, W)`。
2. 用 `resnet18` 或 `resnet50` 提取每帧特征。
3. 用 `feature_proj` 映射特征维度。
4. 将特征还原为 `(batch, seq, feature_dim)`。
5. 输入 LSTM。
6. 取最后一个时间步特征。
7. 用线性层输出 1 个回归值。

### 7.2 训练脚本

入口：

```bash
python PyTorch_nn/train_cnnlstm.py
```

默认读取：

```text
PyTorch_nn/dataset4lstm14/train/labels.csv
PyTorch_nn/dataset4lstm14/val/labels.csv
```

默认关键参数：

```text
batch_size = 8
seq_len = 4
img_size = 224
num_epochs = 1500
lr = 1e-4
cnn_type = 'resnet50'
feature_dim = 256
lstm_hidden_dim = 64
lstm_layers = 5
```

训练输出：

```text
PyTorch_nn/report/cnnlstm14.1/
```

### 7.3 测试脚本

入口：

```bash
python PyTorch_nn/test_regressionm_cnnlstm.py
```

默认测试数据：

```text
PyTorch_nn/dataset4lstm14/test
```

默认模型目录：

```text
report/cnnlstm14.2/resnet50_bs16_lr0.0001_feature256_lstm_layers3_hiddendim64
```

脚本会查找：

```text
cnn_lstm_best_epoch*_val*.pth
```

并按文件名中的验证 loss 选择最优权重。

测试输出：

```text
test_pred_results.csv
test_pred_vs_true.png
```

同时打印 MAE、MSE、平均 bias 和平均推理时间。

## 10. 常见问题

### 10.1 找不到数据文件

优先确认当前工作目录：

```bash
pwd
```

建议工作目录为：

```text
/home/swh/rsenet50_model
```

### 10.2 找不到模型权重

检查测试脚本中的权重路径是否存在，例如：

```text
PyTorch_nn/report/resnet50_peak2peak_best_epoch1472_val0.0023.pth
```

如果训练生成了新权重，需要把测试脚本中的路径改成新的 `.pth` 文件。

### 10.3 CNN-LSTM 样本读取失败

检查 `dataset4lstm14` 中每个样本目录是否存在以下文件：

```text
combined_1.png
combined_2.png
combined_3.png
combined_4.png
```

同时确认 `labels.csv` 中的 `filename` 能对应到样本目录名。

### 10.4 输出维度不匹配

当前任务是单值回归，因此模型输出和标签都应为 1 维：

```text
prediction shape: (batch, 1)
target shape: (batch, 1)
```

如果修改模型输出维度，需要同步修改标签读取和损失计算逻辑。

## 11. 推荐修改方向

后续如果继续整理项目，建议优先做这几件事：

1. 把所有路径集中放到一个配置文件或 argparse 参数里。
2. 补一个 `requirements.txt`。
3. 合并重复的测试脚本。
4. 把 `dataset`、`dataset14`、`dataset4lstm14` 的用途写成固定命名规范。
5. 统一所有结果输出目录，避免同时存在 `report/` 和 `PyTorch_nn/report/` 两套路径。
